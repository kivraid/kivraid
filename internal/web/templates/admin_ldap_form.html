Connection

With an anonymous bind the directory must allow unauthenticated searches. Password write-back lets users change their own password from the portal — it binds as the user with their current password, so it needs no special rights. Password reset is stronger: it lets Kivraid set a password without the current one (for the “forgot password” email and admin resets), so the service (bind) account must have permission to modify user passwords in the directory. Leave it off unless you've granted that.
